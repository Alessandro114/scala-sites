## What This File Is Good For

Use COMPETITOR-RESEARCH.md as:
1. A design vocabulary reference — hero types, palette families, interaction patterns
2. A starting list for manual research — visit the "da verificare" sites yourself and verify
3. A brief for a designer — "make something like X for vertical Y"
4. A pattern library — the Cross-Vertical Pattern Summary table is the most reliable section (pattern-level, not site-level)

Do NOT use it as:
- A definitive list of award winners (some winners cited are nominees or honorable mentions)
- A source of confirmed conversion metrics
- A substitute for visiting the sites directly before making design decisions
